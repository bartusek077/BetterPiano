# BetterPiano

A free piano visualizer with 8K video rendering and particle effects.

## About the project

BetterPiano is an application for creating impressive piano visualizations—with support for QWERTY keyboards and MIDI controllers, gradient textures for keys and notes, animated backgrounds, and WebGL-based rendering.

## Features

- Video rendering in up to 8K resolution
- Particle effects
- Support for QWERTY and MIDI keyboards
- Gradient textures for notes and keys with refract
- Animated background
- Piano pedals
- WebGL-based rendering
